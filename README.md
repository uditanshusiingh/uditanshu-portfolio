# Uditanshu Kumar — Bootstrap Portfolio

A modern responsive personal portfolio built with **HTML5, Bootstrap 5, custom CSS and vanilla JavaScript**.

## Files
- `index.html` — main portfolio
- `style.css` — custom styling
- `script.js` — typing animation, theme toggle, scroll reveal and contact form
- `assets/profile.png` — supplied profile image
- `assets/Uditanshu_Kumar_Resume.docx` — supplied resume

## Run
Open `index.html` directly in a browser.

The Bootstrap CSS/JS and Bootstrap Icons are loaded from CDN, so an internet connection is recommended for those assets. The portfolio itself does not require a backend.

## Customize
Edit the text in `index.html` to change sections, projects and links. Replace `assets/profile.png` if you want another profile image.

The contact form uses a `mailto:` action and therefore opens the visitor's default email application; it is not a server-side form.

## Deploy
You can deploy this folder to GitHub Pages, Netlify, Vercel, or any static hosting service.
